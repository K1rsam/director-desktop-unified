# 网页出图连接简化与状态修复 · 2026-10-19

分支 `fix/web-image-setup-20261019`，基于 `0894551`。只修改网页渠道设置与其连接检查，不替换美术 Skill，不增加多图并行，不提交视频。

## 已修复

- OpenCLI 状态曾返回 `version`，缺少前端必需的 `schemaVersion` 与 `configured`。前端因此拒绝真实 ready 回包，持续显示旧加载占位。现在统一 `chrome-setup/v1` 契约，并用同一合成 JSON 由 Rust 与前端共同验证。
- 默认只显示一张“ChatGPT 网页出图”卡片：打开 ChatGPT、连接并检查。连接成功后自动保存全局绑定并刷新图片渠道；用户随后在第二阶段选择资产制作。
- 地址、凭据、组件版本、旧版专属 Edge 和历史任务恢复折叠至高级选项。连接错误直接显示在主卡片，不再留在加载状态。
- 新连接发现本机服务未运行时，在后台有界启动；存在的服务不重启、不清状态。只读状态检查不自动启动服务。
- 已保存的浏览器在其他浏览器连接时仍可使用。上游 `extensionConnected=false` 可能表示多个 profile 尚未选择，不等于所有扩展断线。
- 显式点击连接时优先原绑定；原绑定无法读取时，只允许自动连接另一个经过核验、账户摘要相同的浏览器。账户不同不会采用；旧任务保留原冻结运输配置与浏览器身份。
- 上游全局 `commandResultUnknown` 是累计诊断计数，不能当作当前项目任务的永久锁。实际任务继续由原请求日志、active owner、Rust 未知提交保护与原回包管理。当前浏览器自身有待执行命令时仍保持等待。
- 连接/状态的单条浏览器命令采用 8 秒上游超时；Rust 状态读取总等待限制为 20 秒，其他操作总等待仍有界。连接检查不会提交生图。
