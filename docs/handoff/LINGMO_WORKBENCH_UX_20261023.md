# 灵墨导入与第四阶段工作台体验改版

2026-10-23，基于 `78461b6`，分支 `feat/lingmo-stage4-import-20261023`。

## 用户操作

在「所有项目」点击 **导入分镜 MD**，选择文件后自动显示集、场、片段、镜头数量。项目名称默认使用文件名，可修改；点击 **导入并打开项目** 后自动建立项目并进入第四阶段。无需先创建或选中项目，不重跑前三阶段，不启动生成。

第四阶段左侧选择文档和剧集、点击本集场次；右侧先显示当前场次及紧凑素材条，再显示片段正文。点击素材进入管理窗口，查看版本、补图、采用候选或添加音视频。原先大段导入表单改为目录标题旁的「＋」弹窗，制作参数与批量操作默认收起，身份与哈希放入详情。

## 实现与数据保护

- 共用 `LingmoImportDialog`：全局入口自动建项目，项目内入口保留追加新文档/独立修订能力，文件选中后自动预览；附件为可选。
- 新增 `lingmo.preview_file` 本地只读、`lingmo.create_project` 本地写入动作，Rust 与前端执行策略同步。
- 预览的 MD SHA 和目录指纹均核对后才建立目录。默认项目位置、稳定文档身份、跨进程锁、pending/committed 回执使双击、响应未知及崩溃恢复不重复创建项目。
- 相同成稿重新导入复用原项目，保护正文编辑和素材。显式选择新的图片包时会补入媒体，不忽略新附件。归档、删除及无有效回执的已有目录不会被自动恢复或覆盖。
- 图片包损坏或缺图时保留成功导入的正文，显示具体问题，用户可选择先打开工作台后补图。导入中的 Esc/关闭按钮均遵守受控关闭保护。
- 场级资产与片段真实引用、不可变原件、原编号、资产版本、冻结任务及 unknown 保护延续原实现。
- 不因 workspace 轮询重新清空场次；保持素材管理窗、展开状态和片段 DOM，切场仍取消过期请求。
