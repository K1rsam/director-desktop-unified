## 后台执行入口

现有 `director-next-core` 是一次性离线诊断程序，不能调用后立即退出并宣称生产仍在继续。增加仅处理 Chrome 图片的持久后台入口，复用现有冻结队列、原任务查询、下载、采用和直接父依赖；不实现通用远程控制服务。

标准桌面和后台入口需要同一 home 的操作系统级执行租约，防止两个控制器重复派发。后台范围仅为本轮项目和获授权的图片任务，不自动恢复其它项目、文本或视频。相同批量请求恢复必须读取原 ledger 和原 job；未知提交仍保留原页与原回执，不重新发送。
