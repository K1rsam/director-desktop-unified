# Chrome 后台控制方案与现场边界

## 推荐的执行方式

复用用户已经登录的 Chrome 配置；软件在全局绑定 profile/bundle 身份。一个本程序专属、不抢焦点的后台窗口内维护固定控制页，每张图使用独立工作页。原图下载、校验、入库、采用完成后关闭对应工作页；结果未知或待下载的页面保留，不能重发。窗口/线程句柄只能辅助定位，不作为浏览器、文档或请求身份的凭证。

网页生成并发默认一张；准备、校验、已经生成的图片下载可独立推进。提高生成并发到二张需要真实后台运行和账户限制证据，当前不自动提升。CLI/API 的既有并行不受此决定影响；衍生资产依赖直接父图成功入库，独立分支可以推进。

扩展仅在必要且安全时重载。重载前核对未决命令、生成回执和未知结果，持久保存意图；重载后按原 profile 和专属页面完成握手，取得实时队列证明后才准备图片。每图都重载、每图另起浏览器进程、随意切换用户页面都不采用。

- 尚未完成：没有任何页面 transport 时仍能安全恢复专属控制页的独立管理连接；长时间后台运行和最终所有图片的真实验收。窗口仍存在不等于页面 transport 在线；最小化也不能证明永远不会休眠。
