# 图片生产与历史

执行器按来源形象依赖 DAG 生产，先少量基础/复杂形态试稿，用户确认方向后批量扩量。`approveTrial` 是明确保存的人工选择，不由模型自评代替。每阶段一次启动，内部队列自动推进，父形象缺少当前图片只阻塞其后代。

Chrome、即梦 CLI、BH 图片渠道共用请求快照、当前图片、历史图片和来源回执。打开页面、检查连接和轮询绝不生图；保存提示词并点击生成才提交。未保存的草稿保留且禁止生成。来源、画风、提示词或依赖变化只过期受影响待提交结果；历史请求、原图与已提交快照不重写。

图片下载后验证 MIME、文件内容及 SHA-256，原图不可变保存，缩略图另存。全部结果可靠保存后自动设置有序第一张为该形象当前图片，其余图片与被替换图片保留历史。生成失败或下载未完成保留原当前图。用户可从历史选择旧图作为当前图；重复查询与恢复不得撤销用户选择。旧形象版本结果只保留历史，不能自动覆盖当前形象。当前图片记录绑定 assetId/variantId/媒体版本，图片切换不删除原图。图片导入成功也直接设置为当前图片；音频、视频素材仍保存身份、哈希和用途。

每渠道独立限流与并发，Chrome 首版 1 路。失败只重试明确未发送请求或由用户启动新生成；收到任务 ID 后恢复只查询原任务。提交结果未知须核对，禁止自动重发。估算费用未知如实显示，实际费用独立记录。接口成功、文件落盘、当前图选择和视觉合格分别记录；自动设为当前图不代表用户已验收画面。

## 直接父形象与并行调度

每个形象保存直接素材父级，可为基础形象或其它衍生形象。基础→西装→西装受伤、初始物种→首次进化→再次进化，均逐级引用实际直接父图，不跳回最初基础形象。没有父级且没有额外图片依赖的形象可立即提交；不同根与分支并行推进，不等上一整批完成。父级的当前图片下载、校验并采用后，立即检查可解锁的子级；不限制为两层。仅选叶子也补齐缺图祖先，已有可用祖先图直接复用。

即梦图片提交、原任务查询、结果下载分别使用本地工作槽；云端等待不占提交槽。槽位仅限制本机短时操作，不限制云端尚未完成的总任务数。当前实现提交8路、查询8路、下载4路，完成事件立即唤醒后续调度；父图未可靠保存时不得提前提交子图。

排队前检查循环、自引用、缺失/已删除父级及来源歧义。父级无法排队时明确阻塞关联后代，不能创建永远等不到父任务的空等待；其它有效分支继续。保存的父级版本、媒体身份与哈希必须匹配，已发送请求不可因改父级而重写或自动重发。
