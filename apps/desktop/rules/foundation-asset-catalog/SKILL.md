# F2｜轻量资产制作目录

交付目标是可直接使用的本批目录，你对自己的目录负责：依据输入原文完成提取、核对并修正后再提交，不交“请Q1核对/补齐”的报告。已知身份沿输入key，只输出本批需要的目录项，不回抄其它批成果或原文。

有`scriptStructure`时按其已明确的正文分型与行范围读source；标题、人物名单、连续性备注不是对白说者，声音人物不自动入画，是否实体呈现仍核对原文动作。

提交前在本次回答内自检：必要实体有无遗漏、用途与场引用是否有原文依据、分类与素材来源是否正确、必要持续状态是否与基础使用一致。能据输入解决的错误直接改好，不转成人工选择；缺字段、格式或程序执行失败不是创作取舍。确实缺少原文依据时保留准确范围的不确定性，不填造事实。自检过程不输出。

同岗内部返修仍按本岗位规则理解原文并修正受影响成果，不退化成只凑JSON格式。返修只交本次修复协议要求的局部patch；已有正确字段和未授权内容保留，不借修格式改变事实。

只登记**持续可见且需要引用的实体**。沿用3000资产图制作的用途：只有需要锁定稳定身份、新外观或持续连续性才独立备图；分类决定建图模板。跨镜复现或动作作用本身不够，普通物件没有特殊外形/身份依据且无持续辨认或交互一致性需求时才留在原文，不用INLINE保留整份杂物名册。必要服装、真实造型和关键物不可为减数而删。

有连续可辨外观、且多镜可脱离角色/场景独立交互的普通物也需稳定引用；只有已验证的角色/场景基线或现有素材能一致承载，才并入配套，不能假设素材库。

## 3000 P2 筛选与分类

- `CH`：有真实人形、有名字或有稳定戏份的个体；基础人物只一条。必要换装或持续可见身体状态是其 `variants`。
- `GROUP`：人群、同学、围观者等群体；不因一句对白机械拆成一批人物。
- `BEAST`：凶兽、神兽、召唤兽、坐骑、虚影等非人对象；不得写成 `CH`。
- `LOC`：真实单一物理地点；`快切`、`各处`、转场标题不单列地点。
- `PROP`：跨镜跨场复用或剧情关键的道具/可见系统界面。

不要登记情绪/临时反应、短暂特效、背景陈设或仅台词提及物。关键物须承载辨认、物证、独特图面或跨镜外形连续性。纯声音不因说话成为人物资产。

必要变体只保留后续需要选对的换装、持续伤势、地点或关键物状态。尺度、姿态、透明度、普通日夜和瞬时破坏不自动触发DERIVE；没有新造型或稳定残损连续性时用场次表现，确有选版价值才用INLINE。不要补造未写服装、外观、天气或伤口；状态解除不建“恢复”资产。

人物造型不设固定套数：明确换装或实际活动所需的功能着装，现有基线不能合理承载时保留必要子形象，单场也可需要；相容日常用途复用，不因换地点拆套。原文明示优先；功能用途可据动作登记，不等于补造具体款式或装备，不凭活动关键词添装备。“众人/二人”等集体换装结合前后身份与实际参与动作归属，不要求人名与衣名同句，也不广播给所有在场者；准备不等于已执行：原文明示需准备的必要造型可保留，但不能据准备动作填实际穿戴集场或推定后续沿用；尚无实际使用定位时以既有`episodes:[]`、`sceneRefs:[]`及变体`note`记录用途与待定位边界，有据集号仍保留，不臆造场引用。临时湿泥不默认独立备图，需引用时优先INLINE，确需稳定选版才另备；沿用现有字段记录差异与实际场引用。

状态判断依据本批原文与相关前批事实：连续时空的伤势、服装、残损不能每集重置，也不能永久无条件继承。说明起点及解除/遮挡/换装/时空跳转边界，只登记有据适用集；不确定时回查相关原文，不把缺少重复描述当恢复或永续。叠加伤势须沿实际服装/形态来源派生。

本批有VO/AUDIO不代表全剧或本场无实体，不能把曾可见的基线降成纯声音；本批声音用法与全局备图需求分开，只有原文明确支持时才排除本场实体呈现。

声音标签不证明实体缺席。逐场核对动作及交接的施动者、接收者：原文明确“把物件交给某人”“某人接过/交还物件”时，不能因同场VO/OS就写纯声音或不安排实体入镜。确实不能判断场内呈现时记UNRESOLVED和准确集场，不自动编造身体入镜，也不能把回忆、想起、台词提及当作实体交互依据。

主资产名用“人物名｜默认服装名”：剧本明确基线服装时用原名，没提才用“默认”。分资产只写其它有据服装/持续状态；首次出现的基线服装不要同时作为基础与一个重复变体。需要保留的动作、临时持物、开关门等信息不等于需要独立素材，留在对应场次原文即可。

## V2 传输规则

沿用现有对象时填写已有 `key`；新对象省略 `key`，由程序生成稳定身份键。不要输出旧格式的 `parent_name`、`scene_refs`，也不猜变体键。基础资产的本批使用写 `episodes`，必要状态写在 `variants` 的 `episodes`；它们都只写实际适用集。实际使用的资产/变体以 `sceneRefs:[{episode,sceneKey}]` 指向输入中的场；无法定位就写 `[]`，不猜场景键。

`preparation` 只表示素材处理：`REFERENCE` 独立准备、`DERIVE` 填真实素材来源、`INLINE` 保留引用但无需独立制图、`AUDIO` 独立声源、`UNRESOLVED` 是确实影响制作而原文无法决定的缺口。剧情关联写 `relationNote`，不是 `fromKey`。人物基础资产可写 `role`；子形象和群像不重复角色定位。

同一实际人物仅换装、添功能着装或叠加持续伤势，须保留未变的脸、发型与体态，必要独立备图写 `DERIVE`，来源是实际承载该状态的直接形象。`DERIVE` 表示目录中的素材依赖，不要求父图已经生成；缺少已登记 key 不等于独立制作，不能把“与基础人物保持一致”的换装写成无父 `REFERENCE`。

非人主体（`BEAST`）同样适用：原文有持续同一主体的证据时，其进化/升级按实际上一形态逐级 `DERIVE`，保留未变身份和有据形态差异，不能每层跳回最初基础而丢失中间变化；同批多层使用下述 `localKey`/`fromKey`。不同独立个体或仅同物种不强连，不凭同名、层级名称或升级关键词猜父与升级顺序；原文缺少连续身份/顺序依据且影响制作时保留准确范围的未决。

同批新建人物基础及换装时，两者均省略 `key`。换装从本人物基础版派生，可交 `preparation:{"mode":"DERIVE"}` 并省略 `fromKey`，由 Rust 在分配身份后绑定所属基础版，不猜基础键。叠加状态从另一同批新形象派生时，为被引用形象声明所属资产内唯一的 `localKey`，派生形象的 `preparation.fromKey` 填该 `localKey`，例如西装 `localKey:"suit"`、西装伤态 `fromKey:"suit"`；可前向引用，可逐级派生，但不得跨资产借用局部键、引用自身或成环。`localKey` 仅本次回包有效，程序只保存解析后的正式直接父键。已有来源沿输入 registry 的准确形象 key。

`REFERENCE` 仍用于真正独立的制作基线：如原文明示不共享实际身体的前世形象、不同独立个体或无素材继承关系的形象。仅有同名、前世/回忆标签、血缘或剧情关联，既不能证明应派生，也不能证明应独立。明确独立时不填 `fromKey`，说明依据；原文与目录仍无法判定且影响制作时保留 `UNRESOLVED`，不按名称强制绑定。提交前核对素材方式与 note 是否一致，换装的身体继承关系必须落实到父链，不能只在文字中承诺。

只返回本批 JSON 目录。不要写 F1 概述、逐集摘要、自评或完整候选重发。

人物 `role` 可用男主、女主、主角、配角、反派、路人。男主/女主须有原文或输入全剧定位依据，不凭性别或出场频率强推，不设男二/女二；结合输入中累积的主线、主要感情线、关键转折与结局证据判断，不只看本批出场数；后批明确证据可在当前授权内修正先前配角定位。不明时保留主角或原分类，新资产未知可省略。子形象继承基础角色定位，不重复填写。婚服等有据换装、伤后独臂等持续状态按实际适用集保留；子形象不等于独立身份，独立神兽也不能仅因召唤关系变为人物变体。

## 桌面运输契约

以上岗位正文迁自现有旧版实际调用。执行只读 INPUT_JSON 原文及输入候选，不联网、不读额外文件、不检索宿主 Skill，不重新抄写原文与对白。

恢复旧轻量目录：资产、形象、普通分集资料和场字段修订不填写 sourceRefs，不逐场列原文编号。模型负责判断身份、必要状态、素材方式及实际使用的 episodes/sceneRefs；Rust 绑定锁定源版本和所声明的实际集场。程序绑定是 SOURCE_SCOPE 范围资料，不是某个主体的视觉事实，不据此推导服装、外貌或状态永久延续。视觉事实由第二阶段原 A15_A 按原文、主体和版本提取。

episodes/coverage 使用输入 episodeId，sceneRefs 为 [episodeId,sceneId]。真实场次须属于本批声明的集号；空使用范围仍是未定位候选，不广播到本批或全剧。同一已有身份与形象沿 registry 的 key，新对象由程序编号，不按姓名合并。preparation 的素材派生与 role/relationNote 的剧情关联分别保存，不猜来源、不允许自依赖或循环。

真正事项证据的 sourceRefs/evidenceRefs、方向依据、拆场切点仅选 schema 枚举的 r:start:end，和输入第一列 row:锁定源前缀:start:end 一对一对应。省去重复源前缀，由 Rust 绑定当前 sourceSha 还原；不重算或拼接坐标，不能引用完整行之外的区间。原文、说者、台词、源哈希和完整覆盖仍由 Rust 校验。方向引用及拆场 anchor 逐字核对；程序执行有据拆场，不为它增设模型岗位。

F2 仅交必要目录，不写逐集长摘要、overview、方向、自评或候选重发。Q1 changes 仅含实际差异，无变化交 changes:{}；省略/null 保留，明确空集合只清除本批授权用途，保留批外结果与已登记身份。普通提醒写 notes，不阻塞本阶段；真正原文矛盾、必要制作取舍和未决事项保留准确影响范围，推荐不等于确认。不增加独立审查岗位或自动重复整批生成。
