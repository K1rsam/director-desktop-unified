# 原文锁与制作范围

原件是不可变证据。Rust 保存 UTF-8 原字节摘要，坐标使用 JavaScript UTF-16 左闭右开区间。每个原行连同原换行完整出现一次；不得删句、改词、纠错、改序或让模型重新抄写全文。显示编号、分集序号、分场标签只是附加结构。

输入是 `LockedSource`，输出是同一原件上的行、集、场、对白目录与待裁决坐标。明确的第 N 集、第 N 场、场景：地点及带时间/内外的集场头才是程序边界；对白提及地点、价钱、比分、比喻与空标签不产生场界。资料区不得变成制作集。集号重复、错属场号及无明确边界的正文保留并报告，显式范围决定只改变分类，不改变原文。

对白目录区分原说者标签、原句和声道。标签是来源字面，不是资产身份；人物同名、别名和形态必须由制作基础关联。OS、VO、画外与系统音分别保留，不因镜头看不到嘴就改成 OS。表演提示不是新说者；普通台词中的冒号不是分说者依据。共同对白或归属歧义保留原行，局部处理，禁止猜定。

`SourceDialogue.quote/range` 仍是完整原段，不因拆分演法改写；新增 `spokenSegments` 和 `performanceSegments`，均为程序按同一原文回读的 `{text,range}`，range 是绝对 UTF-16 左闭右开区间。说者标签中的括号标注和台词中的平衡括号演法单独保留，发声片段按原顺序拼接；字面引号中的括号文字保留为可发声原话。不得把演法念成台词，也不得让模型改抄台词。旧源可缺新数组，经完整旧契约校验后程序重解析补齐；已有新数组被改词、调序、错坐标或漏段必须拒绝。

验收由程序实施：摘要匹配、UTF-16 边界合法、完整覆盖无重无漏、引用回读一致、对白全文/顺序/说者/声道一致。未知结构不得悄悄按旧规则降级。原件、标准制作包与每次模型投影分开；只压缩当前发送材料里已证明重复的证据，不删唯一有效来源。
