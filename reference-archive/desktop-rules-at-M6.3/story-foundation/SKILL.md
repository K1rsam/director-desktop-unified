# 制作基础与资产身份

一次阅读当前范围的锁定源行，输出 `foundation/v1` 的必要前情、资产身份、形象版本、适用集场、来源派生关系与视觉事实。输入包含本批原行、首次资料行和已登记目录；每批只申报正在提供的制作集，不假称看过未提供集。不要另起审查岗位、重读整剧或写逐场长摘要。已有基础按选集更新，范围外成果不重新输出。`confirmedDirection` 是用户确认口径，原样保留；未确认方向只作候选，结合 `priorDirection` 累计，最后所选批次才汇总范围匹配的候选，不把首批情绪或少量片段定为全剧方向。

角色、群体、异兽、场景、道具使用稳定 `id`；姓名只用于显示。已登记身份和形象沿用 id；有据别名归并，不能仅凭同名合并不同人物，也不能为改名新造身份。基础形象和服装、伤态、进化形象按 `(identityId, variantId)` 识别；不同身份可各有 base。派生来源优先本身份，跨身份引用须唯一。禁止循环、失踪父版本或把设计提案当源事实。资产行 ID 由程序保留/生成，模型不填写 `assetRowId`。

形象 `scope` 明确为 `SCENES`、`GLOBAL` 或 `UNRESOLVED`：SCENES 的 scenes 与 applicability 同为真实 `{episodeId,sceneId}` 对，每场须有本场引用；GLOBAL 要给来源支持的非空 reason，不能从一次出场推为全剧服装；无法定位填写 UNRESOLVED、空 scenes/applicability，绝不表示任意集场可用。准备中的必要造型可登记但不得假造实际穿戴范围。只保留需要稳定辨认或选对版本的资产，普通杂物、瞬时反应不独立建图；有据换装与持续伤态不能为减数删除。

事实只提取图像生产和分镜执行所需的外形、材质、尺度、场景功能、持物/伤势/能力/知情及变化。每项有源行引用，原句由程序回读，无需重抄。区分 `SOURCE` 与 `CHARACTER_CLAIM`，并标记 `STABLE / STATE / TRANSITION`。STATE/TRANSITION 必须绑定准确 variantId；无法归属交局部 issue，不能传给所有基础/变体。持续状态沿有据时空延续、换装或解除边界处理，不每集重置，也不永久继承。角色自述、推测与未来计划不升级为已发生事件；后集出现的定义不能倒推为前集已知或已穿着。

原文未限定的非剧情美术细节留给第二阶段。不要创作分镜、镜头、对白或站位，不增加出入口、能力、战果、关系、身份和剧情功能。冲突列局部问题及引用，保留并存来源，不综合改写成无据结论。

输出所有引用只使用输入给出的 rowId。资产 id、同身份 variantId、fact id 不可重复；每个已定位形象指向真实场和有效源行。issues 标明 assetId/variantId/episodeIds 及来源，只有必要未决才 blocking。图片缺失不阻止第一阶段；未定位形象和状态事实只阻塞相关范围。程序先校验、物化原句，再将文本回包标为可复用；无效回包保留拒绝原因，不冒充已完成缓存。
