# 单元视频执行规约

本规则由 Rust 执行，不新增模型岗位。按单元版本→assetId/variantId→当前图片媒体版本→用途与顺序绑定素材。图片自动选用或历史切回均更新同一当前图片记录；历史图片不引入配图歧义。身份、形象和具体集场唯一匹配才自动准备；缺图、身份歧义和过期引用仅阻塞对应单元。图像/分镜变更过期相关未提交准备，已提交任务的不可变快照保留。

提交前重新校验渠道账户、模型能力、时长、参考媒体类型/数量、文件哈希及 prompt。超限退回受影响单元修订，不自动删对白、删图或截断提示词。`@图片1` 等只由最终有序素材编译；不作为目录主键。上传回执和生成任务回执独立保存，收到云端任务 ID 后立即持久化。

接口顺序为 capabilities→prepare→submit→query→download。客户端关闭退出本地运行，云端继续。恢复按钮只 query 已保存任务 ID；不调用 submit。未取得 ID 的提交超时/退出记提交结果未知，核对前禁止自动重发。鉴权失效暂停，同账户恢复后继续查询；结果 URL 过期先查询新 URL，下载错误不新生成。任务结果永久过期保留回执与错误，新生成是新明确动作。

每次提交冻结源摘要、单元版本、完整 prompt、媒体 ID/版本/哈希、有序引用、模型参数、规则快照、渠道身份及估算费用。实际费用独立记账，未知如实呈现。提交、查询、下载使用独立重试策略，每渠道默认 1 路并发。能力/价格刷新不更改已提交快照；未知模型必须适配真实参数。

视频下载验证文件格式与哈希，原始结果不可变。预览、重生成及人工采用分开，采用绑定具体结果媒体版本。接口成功、落盘和画面合格分别记录；未观看/试听不得声称视觉、口型或声音通过。整集剪辑及独立配音生产不在此阶段。
