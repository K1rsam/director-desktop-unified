# 相机路径与切镜的具体判别

适用：一镜里既想读近脸又想证明全身、或从人物正面跳到肩后视点。

连续方案：相机起于甲的右侧斜前，脸与肩同框；沿甲右肩外侧小弧后移，到斜后肩旁显出前方乙，始终交代身体和目标位置，落幅转焦乙。人物不动也能换观看位置，但相机真的走了路径。
反例：起幅正对甲眼睛，写“轻轻升高/转焦”就落成甲肩后看乙；焦点变化不能搬走镜位或穿过甲。

切镜方案：镜1近景读甲眼神，镜尾看向乙；镜2从甲肩后看乙全身，各有时长，眼神与位置连续。真的切了机位就有两个镜条目。
反例：一条camera写“先眼部特写，再切全景”，transition又写“没有切镜”；或“随即切同一镜内连续摇焦”。这不是高级镜头，是互相矛盾的执行命令。

支持镜：读脚踩剑/踏步时用全身或专门接触画幅，承住重心后再近脸；若同镜由脚到脸，给明确俯仰/后移和落幅，不让脸部特写同时承诺完整脚下关系。
反例：人变成远景小点，却要求观众读细眉；或为保留全部内容把关键脸、手、脚挤在不可读画幅里。

方案依情绪和信息任务选择，不规定每次全景开场、每镜移动或固定镜数。修的是可见性，不能以修空间为由删除主要人物的表演。

接触方案：父亲与儿子原隔桌，父亲在通话末句自然起身绕向桌角，挂断时已到肩旁，另一手拍肩；起身与原话共时且不提前改源要求的接触时点。若起初就邻座，则无需额外靠近。反例：只把“拍肩”改成“手与肩同框”，实际距离仍未建立。

主观退出：Q版脸逐渐恢复原比例、同机位跟着同一动作，可是一镜；幻想算盘手匹配切到办公室持机手，则写两个镜条目并重排跨切OS。两者都合法，但不能一条说明同时要求两者。
