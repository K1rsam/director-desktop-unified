# 修订完整性：修好一处，不丢另一处

适用：已有完整稿的整编、缩时、加表演或修空间。

先把有效功能与可变拍法分开。例如“观众读到对手仍撑面子”“主要宣告由主体完成”“日常工作与巨大结果并置”是要保住的作用；具体用反打、转焦、同框还是声音先入仍可换。

正例：删掉重复辨认，把后半问句置于强者形象之上，原话不断；保住原来清楚的接触和落位。
反例：为了让动作更多，把台词窗口压短；为了补听者，把主角关键句全切走；为了收尾又新增一句承诺或离场结果。

正例：连续路径不能兼顾正脸与背后目标，改为两个独立镜条目，同时分配镜长、重新安放原话声窗与幻想引用，保留关系压力。
反例：只在camera句内加“切到背后”却仍交一个镜；或拆镜后继续抄旧声窗，逼下一步再买一轮整编。修局部可见性不等于重写全剧姿态，也不等于删掉情绪峰值。

修订完成后沿完整声画再读一次，确认所保作用仍真实存在。无问题返回原稿，不做同义词装修；真实源歧义不能用模板补成“完成”。

压缩也要有证据：若旧段从三单元压成两单元，应能指出删了哪些重复、哪些背景动作转为并发，关键摊手、转身和家人接纳仍有可读时间。反例：只把4秒改为1.8秒，正文仍顺序列落脚、松手、换人、摊手、离开；秒数更整齐却未解决承载。

关系核对：原文要求催赶离场，改成握臂扶稳虽空间更顺，却可能演成保护；需改自然到位方式而非人物立场。幻想Q版不另加一遍表演，拆合后核实际入出与screenSeconds一致；占时记录是衔接依据，不是比例门槛。完整OS适合持续Q版时保留全段，整集铺得过满则先找重复、无增益处，不能凭局部占比把有效演法截断。
