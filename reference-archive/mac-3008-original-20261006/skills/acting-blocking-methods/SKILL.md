# 情绪夸张与表演调度核心

此模块是所有题材始终生效的情绪/表演层，嵌入主创与整编，不是新增岗位，也不受幻想开关控制。负责正常角色的夸张情绪、表情、气息、动作与人物关系；Q版、漫画替脸、图形表情、动物化和非现实变形的具体画法归fantasy-expression-methods，不能以“表情夸张”为名在本层启用。

每个短句与情绪拍都要把当拍感受演得鲜明可见，包括说者、听者和沉默中的持续用力；不只挑高潮才设计，也不把每句都升成同样的大喊或新反转。先构想谁以什么身体/关系变化击中观众，再用人物要对谁做什么、遇到什么阻力组织过程。感情戏的心动、强忍、委屈与决裂同样需要幅度和力量，不因“严肃、细腻、幻想关闭”退成微笑、看一眼和静站陪读。高情绪拍选够幅度的主动作，脸、重心和手势围绕它协同；安静的力量则由可读的绷持、呼吸或双方用力差兑现。

## 策略与幅度

- 按每拍、每个人处理刺激：此刻继续试探、转为遮掩、求援还是顶回，由新信息与阻力决定。日常基线要有任务和注意对象；关键词真正抵达时，节奏、重心或关系位置随策略改变，不把开场的严肃/从容一直演到底。
- 放大必须有看得见的身体结果：笑意撑开脸颊、胸肩带动双臂释放；维护权威时下巴还抬着，嘴角却失守；恐惧让脚掌寻找支点、躯干先撤而手仍抓紧。小动作也要让观众看见用力、失衡、停住或松开的变化，不能只写“猛然震惊”“用力挣扎”。
- 同样吃惊，遮丑者先挡证物，否认者欲退又探，求生者先找支点或退路；选符合此人策略的动作发展。面具与泄露可相反，但不强制每场双重情绪；反转后也可能更疼、更警觉，而非全员同一张大嘴。不用幻想时基础表演也不减弱。
- 听者在关键词抵达时处理信息，不空脸排队；长句可在画外连续，画面给有效倾听或行动者的完成。先让关键接触、制动或关系动作以适合此人的幅度成立，再由反应放大其意义，不能用几张惊脸代替发生过程；也不因“主角优先”切掉真正属于听者的转折。
- 立场由动作关系决定，不仅看情绪形容词。握臂“催他下去”与“扶他落稳”会改变观看判断；保留源对象、主动性与策略，不默认温柔处理更合理。表演写可见发展：此前在做什么，哪句改变了它，随后选择什么；“没有误以为……”等解释放在必要边界，不占用正向表演。

面部也是行动，不是全身动作之后附一句“愤怒/震惊”。进入近景时让观众看到具体变化：想把笑撑住却在新信息上卡断、想压住呼吸却从口颊泄出、视线由寻找支点变成迎住对方；眉眼、口颊、头颈与当时身体用力有联系。正常比例角色保持脸型与五官结构，用大幅眉势、睁眼、张口、颊部牵动、呼吸卡住和下颌用力提供冲击；极近取景仍可强烈。眼眶含泪、泪水滑落、紧张脸红或痛哭扭曲仍可属于正常表演，写清生理变化与用力，不换漫画五官、图形泪滴或橡皮结构。面部变化随同次身体/发声动作发生并接续余势，不把前后表情摆成两张静态脸。

表情跟发声同相位：怒话中咬肌可以绷紧，嘴仍随字音开合；闭唇、咬牙或屏息落在确实无词的拍点，随后再放开发声。吞咽、呼吸和身体用力也不抢占同一段必需口型。配角留在原位时仍承接最新事件：注意对象、手势或气息可随结果改变；源有刻意不回应则保留，不强加每次重见都动一下，更不把未知态度补成嘲笑、失望或新知情。

前后强拍区分力量性质，而非都“大声＋大动作”：被刺痛时冲向对手，与决定后站住重心、向外打开关系，是两种演法；得意压人和反转后的体面失守也不同。持续较力或争辩时，先找源已有的加力、察觉无效、话锋变化、对方回应，让投入、视线、呼吸或观看对象接住这些差别；不是每镜再证明一次“很用力/很吃惊”。无新策略时，压力积累、投入与结果的落差也能推进，不强造转折，不为后拍留额度而压小前拍。

用关系的前后对应放大情绪：原先主动占据高位、等人仰看的人，受挫后可能需要抬头找同一人的目光；方才索要拥戴的手，后来可能转为遮丑、求援或推开他人。只选源发展支持的对应，不为构图漂亮提前让群众撤退、让危险解除或改变谁伤了谁。保留原文已写好的重心、视线和犹疑；新增设计把它拍得更清楚、更有幅度，而非再演一遍。

若选择“尝试却失败”的演法，把尝试对象和失败原因拍出来：手明确抬向要触及之处、阻力使动作中断、身体转回必要支撑；不能只写“想恢复体面”配无方向的微抬。先在可读画幅完成有效变化，再转到尺度/关系后果；不把细小动作留给已拉远的人影。这是可选演法，源只需一次对视或沉默时，不另造一次失败动作凑闭环。

## 动作有记忆

不先把镜头锁成半身，再只比较眼口和肘线。选符合人物的主动作：惊喜使人蹬起、抱住同伴或蹿到高处；嘴硬者后撤失衡却抢着探身顶回；怒意可让人登上桌面占高位。位移、接触承接、重心反转和节奏顿挫都能放大情绪，摄影为它选择看得见的画幅。动作未在原文逐字指定不等于禁止设计，也不要求这些动作全部出现。

例如暴烈的人当众质问不公，可借手撑桌缘、脚掌落上桌面、胸肩前压把原句顶向对方，落脚后衣摆再追上；不是多喊一遍或凭空打伤人。另一位真正冷硬的人可能留在原位，以对方不断退让的距离显出压力。幅度按角色与语境，不把登桌变成所有愤怒的固定解。

让动作有可辨的动力相位：起势把力量和注意蓄到哪里，哪个落词/接触使它突然释放或被截住，身体如何制动，衣发与物件怎样稍晚追上。脸、头颈、胸肩、手、躯干、膝足与重心围绕同一主动作联动，正常比例的面部结构稳定、讲话口型可读。回落可以直接接管下一动作：前脚制动带动转髋，转髋顺势送肩，手臂沿余势接下一次源行动；披风尚未收回，新动作已经改变它的摆向。按实际动力写速度、变向和受力，不把每镜都写成“起势—爆发—站好—等衣服停”。非人主体按耳尾爪、脊背、重心与自身结构表达。

连续动作允许高密度：主体发力、衣料滞后、物体响应与视线转移可以共时，真正需要前一步完成的接触与结果才串行。正向写法如“踏稳前脚急转身，袖口沿旧方向甩出；他借转势把原持物送向目标，镜头沿手臂滑到接触点，袖摆此时才折回”。这是动力与观看接续的例子，使用本剧已有持物和行动，不自动新增招式。人物停住时，余势、受光或另一人的反应仍可推进画面；所需停顿有具体读点。

接触至结果沿可理解的动力传递：来势、接触面、重心/支点变化、脱离与落点接得上。靠接触传力的动作，在仍接触时让身体/物体接到方向，离开后延续已获得的冲势；例如“杆身带偏仍握杆的双手和肩背，握口滑脱，身体沿退势踉跄”，而不是脱掌后才凭空被杆带走。交接物品也先有接者承重再松手。必要先后可快速连成一股，不逐步摆停；源有隔空作用则沿其已给通路。方向可由斜面、转体或已有障碍改变，接口须可见，不要求严格物理仿真。源明确来势与结果不改，不新增能力圆场。局部作用与结果范围分开：击中胸前若引发整套护甲碎散，要让裂纹与后续全身状态覆盖该范围；离手、解封等同理。

反应先接到源中可感的触发：看到逼近、听到关键词或接到冲势，再让视线、气息和身体同拍变化；无需等整句或余势结束。源只给“一步逼近、膝沉未跪”时，可突出逼近与失稳的同时关系，保留尚未说明的机制，不自行认定为主动服软、恐惧撤脚或真实气浪。写清发生了什么，不为解释清楚而改变行动主动性、能力或决定；脸上的惊惧也不能倒推新增因果。

高燃姿态先给清楚的对向发力。例如源本来就有借腿引巨弓：双手向胸侧拉弦，前伸脚掌抵住弓内缘，伸直腿与后拉手臂形成两股相反力量，弓身随张力弯曲；松指后弦前振，前腿卸力回收，身体被释放的余势带着旋转。摄影先读到手、脚与弓的关系，再追释放方向，衣发从拉弓时的后飘转为旋身外甩。借的是支点—蓄力—释放—响应的机制，弓、能力与战果只在本剧已有时使用，连招速度按这条动力链设计，不套统一每秒招数。

威压可以由环境响应显力：源已有力量展开时，目光抬起与气流扩散同拍，衣角先贴向身体，近脚的尘土沿地表被推出，远处草叶随后同向伏低；受压者的膝足与肩颈接住这股力。强度由源能力与当拍关系决定，轻压也可只改变呼吸和一小片尘纹，源允许的强压再带起碎石/空间波纹；环境响应给力量证据，真实毁坏须有源依据。没有真实威压能力时，用站位、距离、视线与摄影的心理压迫成立。

情绪转折也只发生一次：源在最后抬脸顶回，前镜就不能已“不再躲目光、昂首面对”，后镜又无新刺激地缩回去重演。可有试探、受阻、再争取，但要有对应的刺激和行为差别，不把每镜各写一个完整反应当递进。旁人的大笑与主角的窘迫可以同场放大；看谁在嘲、谁在承受，不因出现滑稽造型就取消受辱的荒诞感。

拿起→持有→移动→接触→松手只在发生变化时交代。夸张表演可跨镜、伴随原话继续，口型保持可读；源文的持物、伤势、真能力、知情、说者与声道不随表演强化而改写。非人主体依自身耳、尾、爪、重心和避让表达，不强装人的五官或手。

接触前先确认双方距离、坐站和障碍：隔桌的手即使入镜也不自动够得着肩。可让靠近与前句话共时，在触碰前到位；不为补接近再演一次起身，也不先触碰后才补位置。

## 正反例

好：感情戏里源有“追问—拒答—决意离开”，追问者前跨逼近，尾字随呼吸顶出；对方不答，伸出的手抓紧后停在两人之间；决意出口时追问者抬脸迎视，说完才转身，肩背仍绷着，衣摆追上转势。痛与决绝由同一次动作变化传递，每句都有情绪力量，不靠换画风或插字来提示。
坏：因为幻想关闭就全段低头轻声；或每句都哭喊、跺脚，把关系变化演成同一强度。例中动作须适配源明确的先后与人物立场，不移植新决定。

好：源有热烈喝彩，一人蹬起脚跟、双拳收胸笑得仰身，转向同伴时重心带过去；同伴接住热度，跨前半步向下一位猛一展臂，期待对象成为新的观看中心。也可设计拥抱、后跳再探或其它符合关系的动作；正常比例一样能大幅演出，不需先得到Q版许可。
坏：旁白写“全场沸腾”，可见人物却只有指一下、点头、嘴角上扬；把台词说得大声当成身体亢奋已成立。

好：同一人前拍前倾报喜，误判被戳破后，原来邀人看的手翻成指指点点，笑得仰身又凑近同伴；承受者的手、眼神或姿态随刺点改变。群体齐反应可形成浪潮，随后以有不同动作的代表者读清关系。
坏：甲乙丙只轮流换脸念嘲讽，受辱者连续十几秒只在远景站着；或为夸张把尚未释怀的受辱者也画成陪笑。

好：真正从容的强者保持原来的承重手势，对手不断压低重心却压不动；脸的冷静由这份有力反差成立。
坏：认为强就得喊、喜悦只能笑不露齿，或把“有策略”误当“不许失控”。例中的动作可替换，目标是让该拍的幅度与人物立场一起成立。

好：想装作没被击中，嘴角硬提、下巴仍向前，手却把扶手攥紧；说话还在争夺位置。
坏：写“依旧高傲”，画面却无原因后退、垂头、全身发抖。

好：源文确认脱险，先前硬撑的肩背松开、身体一轻；下一句传来新的威胁时，脚跟重新落稳，手截住尚未放开的动作，重音转硬。
坏：一听好消息就全程弹跳，忽略下一拍的危险；或所有强者都冷笑、双手不动，所有开心都做同样星眼动作。

好：他已获知有利消息，听对方继续误判时先抿笑，笑气牵动颊与肩；轮到自己说话才放开，最后收笑作判断。重点是忍、漏、放、收各有语义触发，不是固定四步清单。
坏：只写“笑得很痛快、张开双臂”，四句立场变化都用同一笑脸陪读；或为多一个爆点，把对方每句话都切成惊讶。

源中的普通任务未结束、也未被新情境取消时，可用它的下一小步收反差：继续修补、收拾或核对不等于第二次超常出招。若这一回归承担情绪闭环，就把实际动作写进可见画面，不只“持物/看过去”加拟音；源已中断任务则不硬恢复。例子用于推演，不是菜单；四个专业只细化同一拍，不各加一轮反应。
