# 20261027-v0.2.0-production-flow

本版落实流程提效，不改变完整主创→整集整编→非作者独审，不降低夸张表演、有效快运镜、已授权幻想与适合段落的覆盖。

- 开稿只等待完整本集源、有效方向、必要前情与完整分镜设定。稳定身份、状态、动作条件和空间采用后直接引用；完整制图资料并行补齐，不等全库美术设计。
- 初始可生产资产包提前交。新状态/Q形态或实际冲突才局部补项；一般按批次处理，最终按采用稿收口，不增加逐集全库查重与兼容证明。
- `record-image-design`批量追加制图资料，不改资产行、assetRevision及分镜采用指纹；父制图变化只令真实图片派生项待复核。真实分镜约束变化仍走revise。
- 所有编辑性时间、地点、身份、等级卡统一交后期。新三岗合同及新采用路径要求`video-prompt-v1`，保守拦截明确后期/排版指令；原声、真实场内字和系统信息不删。服装仍随当前图片，保留抓袖/脱衣等必要动作和剧情线索。
- 正常→婚礼→婚礼带Q的直接父链保持；有Q片段选同造型正常＋3D Q同图，无Q片段选正常图，不把设计祖先自动加入视频图片引用。

运行与接收合同见[资产生产合同](asset-production-contract.md)。分离制图显式输出image-queue-v2，旧完整设计仍输出v1。当前本机资产项目仅认v1，本轮未改该Skill，需接收侧适配v2后才能直接消费新队列；未接入不阻塞分镜，不能改版本标签冒充兼容。旧生产工程不自动迁移。
