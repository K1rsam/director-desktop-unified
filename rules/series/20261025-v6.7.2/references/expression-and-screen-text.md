# 表现方向与画面文字决定

阶段1通读完整输入后，在原有一次核心方向确认中处理本合同。主控在现有项目决定中保存版本、适用范围、源依据、建议及实际采用依据；可用 `decisions/expression.md`，已有等价文件直接复用。用户明确委托本项目自行决定时按委托采用并注明，不能伪记为逐项用户确认；已确认且同类同范围的决定直接继承，不因升级或换集重问。

## 默认主动增强，再按具体戏调整

本Skill默认要求**加多、加强**，不等用户另提“增加情绪”。普通剧本也要从源情境、人物关系和当拍心思中主动发展有效的表情、身体行动、互动与观看变化；原稿没有强情绪词，不等于只准平读、点头或微笑。增强的是演法，不新增剧情事实、原话或人物动机。自然画风、自然表演不等于低强度；强烈也不等于全员吼叫或喜剧化。

两层分别兑现：**第一层是表演强化**，普通段落就应比照读原稿更有可感的情绪进程，适合的段落进一步采用更鲜明、更高幅度的夸张动作、关系反差和有冲力的摄影；**第二层是幻想强化**，在允许的范围主动寻找更多有增益的机会，并把形体、尺度、空间、材质或关系作用做得更大胆、更充分。表演不因幻想关闭而减弱，幻想也不能以贴纸、Q标签替代表演。适合度按具体情境判断，普通题材也可能有适合幻想的局部，不能只给喜剧开这扇门。

“更多”指更多成立的情绪起伏、互动和不同幻想作用被实际写出，不是硬加剧情、逐句切镜、重复反应或拖长时间；“更强”要在身体、关系、画幅和声画重音中读得到。幻想的增益可以是更强感受、想象趣味与视听冲击，不必新增剧情信息或更省秒数。必要的安静、悲痛和克制仍可有强压力与反差，不拿它们作为整篇温吞的理由。

**“多点适合的段落”是覆盖要求。** 通读后要沿全剧情绪与人物关系主动找到更多可成立的加强段落，并在许可内落实夸张与幻想；不能只挑少数显眼高潮反复加码，就认为完成了“更多”。普通对白、等待、试探、误判、关系互动、过渡和配角反应也纳入机会扫描，判断具体演法能否让该段更鲜明、更有趣或更有冲击，而非要求原稿已经夸张、已经像幻想段落。不同位置各有独立增益就积极采用；选择依据记录在既有emotionContract和候选中，不新增逐段审批或配额。强度与覆盖分别复核：一处做得很强，不抵消其它适合段落被保守漏掉；不为覆盖捏造剧情、重复同一作用或强行把每段都幻想化。

## 分别落实三项表现倾向

| 项目 | 可提出的方向 | 采用后检查什么 |
| --- | --- | --- |
| 情绪强度 | 默认主动增强；适合的段落更高幅、更充分，用户可明确调低或另定 | 压住、误判、爆发、反击、接受等关系变化，是否通过表情、全身动作、空间和对手反应被看见 |
| 镜头速度 | 随情绪主动参与，适合的段落有冲力、速度和尺度反差，用户可另定 | 动作/关系触发、运动速度与路径、命中信息和清晰落点；快慢有功能，不把每镜写成缓推或急推刹停 |
| 额外幻想密度 | 允许时主动发掘；适配丰富的作品默认提出多处、更大胆的方案，用户可另定 | 有源锚的不同机会是否形成有变化的想象与实际演出，而非标签、贴纸数量或每镜变形 |

每项给出默认增强如何适用于本剧的简短建议、全剧依据与必要局部例外；看完几场不能冒称全剧建议。所有题材都主动寻找可增强的情境，喜剧、强反差、荒诞或主观心思丰富时尤其应提出更多、更强的夸张与幻想，两层同时发展，不等用户先抱怨。推荐不是采用，仍按实际幻想模式保存选择；不能只凭题材名给固定密度。密度、形变幅度与搞笑程度分别判断；痛苦、死亡和悲剧不为丰富幻想而喜剧化。

额外幻想的授权仍独立使用 `recommended / all / off / review` 及实际选中ID；密度不扩大授权。`off` 与明确取消优先，源明确的梦境、Q版、法术继续按源；关闭额外幻想不降低表演和摄影力度。快摄影不要求加快念词，不删必要的接触确认、辨认、悲痛落定、静默与悬念。未另定强度时记录“按Skill默认主动增强”，不能伪记为用户逐项回答；已有明确的克制、强度限制或幻想选择优先，只有自然画风标签不视为减弱指令。旧采用稿不因升级自动重写，新创作及获准返修范围才执行本版；真实冲突并入原有一次方向确认，不重问有效决定。

## 系统呈现先核源，再判断是否需选

源有剧情系统时，按[系统呈现合同](system-presentation.md)直接沿用原文明示的呈现方式，在可见执行消息说明形式、依据与生效范围；仅将未明确、真实冲突或用户要求改编的部分纳入同一次方向确认。按系统分别保存实际采用依据、源约束、可见/可听/接触范围及生效版本。系统原声、实体/界面、编辑叠字与额外幻想不是同一个开关；采用记录供各岗位实际落实，已有决定不逐集重问。

## 文字先分类，再决定呈现

| 类别 | 处理 |
| --- | --- |
| `timeCards` 时间说明叠字 | 如“次日”“三年后”；集中确认是否采用及适用范围 |
| `identityCaptions` 姓名/身份/等级说明叠字 | 人名条交后期制作，只进独立后期资料；不写入分镜生成正文，也不写“后期添加XXX”等占位说明；不得提前揭示秘密或升级 |
| `otherOverlays` 其它编辑性说明叠字 | 有实际候选才提出，按类别或具体项目确认；前两项同意不自动授权本项 |
| 场内实体、屏幕内容 | 墙字、牌匾、信件、直播弹幕、系统面板等按源载体、当前可见者和时点保留；不随额外叠字开关删除 |
| 幻想表现字/对白字幕 | 前者随已采用幻想及表现许可，不能借信息叠字偷开；后者不因信息字卡获准而自动增加 |

源写“字幕”“后期添加”只是来源/制作标记，不自动证明上述叠字已获准。先判断是编辑说明、真实载体还是剧情必需信息；含混时核上下文，确有互斥读法才问最小问题。关闭叠字只关闭该呈现：原件、源行、时间跨度、身份事实、原对白及必要剧情仍保留，也不擅自转成新旁白。若文字本身承载角色行动或必要揭示，不能按额外装饰直接删去。

先分交付去向：**人名条以及其它指定后期制作的编辑叠字，只写独立的 `postproduction-notes.md`**，记录源坐标、集/场/单元/镜号、准确文字、位置/占幅、样式和入驻退触发。它与生成用MD分开交付，不复制到通用提示词、单元/分段头、初末态或逐镜六栏；连“此处后期添加”“不生成人名条”也不写入这些字段。源行及onscreenTexts仍完整留在内部source，覆盖可引用该源行，不等于要求上屏。没有后期项目就不创建空表。

本次确已采用且由画面生成承担的时间卡、其它叠字或幻想字形，才在对应镜头写准确文字、位置/占幅、样式和入驻退。尺寸按画幅与用途选择，不套全剧默认。场内铭牌、信件、系统面板按真实载体及知情范围呈现；人物原话确实提到人名条或后期制作时，原话仍逐字保留，不能按关键词删除。后期身份说明不能让角色提前知情，也不能擅改成旁白。

## 供料与复核

给统筹、主创、整编和独审供同一版本的适用决定及默认增强要求；短卡仅投影本次需要部分，同时带出处。整编按实际正文核三项倾向、已选幻想及字卡。只有原话和事实正确、可成立的加强机会却被保守略过，属于具体内容缺口，须据源返修，不能全归为可选美化；已充分有效的静镜和克制段不为交差硬加动作。偏离已采用方向、削弱应有情绪回报的改动，在现有revisionNotes说明具体依据；按源成立的慢停无须逐项写审核解释，局部理由也不能成为全剧保守化的通行证。推荐强度、标签、字卡清单和兑现声明均不能代替实际镜头。

主创、整编发现先前漏掉的有效幻想机会时，在允许自主推荐/采用的既有委托范围内，交主控新建同版计划与选择候选，补全实际正文并核验后再一并采用；这属于正常创作补足，不另加用户审批。off、逐项取消、仅执行已选项或尚待用户决定的review范围不得越过；无此授权时先保住第一层强演出。没有采用的候选仍不能私自画入，也不能把候选漏列固化成永远不可补的限制。具体执行按[本地补漏步骤](production-contract.md#额外幻想补漏的本地执行)：新候选版失败时保留原采用计划、选择及正文，不靠补ID或兑现标签冒领未改镜头。

源中可疑文字另留精简处理索引：源位置/原字、类别与载体、采用或关闭依据、实际落镜或事实保留位置；同类规则可共用一条决定，不逐字卡审批。新稿和返修只更新受影响范围，完整原声、已成立表演、尾态与素材依赖照常核对。

本地 `onscreenTexts` 是保真的源目录，**不是必须逐项上屏的指令**。保留其原文和全部场/事件映射；关闭叠字不能删源节点、伪造“已上屏”或改成元信息以骗覆盖。可在相应事件的相关镜头保留源引用，并在处理索引明确它只承担已关闭呈现/保留事实的来源。现有工具检查引用覆盖和可见字段回读，不理解此分类、许可或表现强弱；这些判断必须读源、读决定、读实际稿，不能宣称程序自动保证。
