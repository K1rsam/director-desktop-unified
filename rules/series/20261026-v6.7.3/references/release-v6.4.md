# v6.4：子代理模型选择与仓库更新

版本：`20261020-v6.4-subagent-model-selection`。

正式制作的首次子代理派发前先让用户选择模型及思考强度，首选推荐 `gpt-6.1-sol` / `high`，同时推荐 `gpt-6-astra` / `medium`；其它选项允许用户自行输入具体模型、版本和强度。推荐或预选不等于已选，未答复不派发；本次请求或同一制作工程已有明确选择时沿用，不逐集重复询问。仅解释、安装和维护时不触发制作提问。

选择贯穿源接入、资产、作者、整编和独审，用户明确分角色设置时遵从。由主控保存选择依据与适用范围，派发时通过宿主真实支持的模型和强度参数落实；当前工具使用 `model`、`reasoning_effort` 及 `fork_turns:"none"`。不支持时说明限制，不静默替换、升降档，也不改变总控或全局配置。执行细则见[调度供料合同](context-and-dispatch.md#子代理模型与强度)。

新增机器可读 `VERSION`，同步主入口、使用说明、来源和验证记录；统一从GitHub仓库的完整Skill目录安装或更新。保留同一提交、旧版备份与分发校验，不覆盖制作工程。本版未修改可执行工具、测试、创作方法和导出协议；旧验证作为历史证据保留，不冒称本次已完成真实模型派发、Mac运行、平台导入或视频质量验证。
