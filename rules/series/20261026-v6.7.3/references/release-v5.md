# v5 更新与适用边界

版本：`20261019-v5-expression-consent`；基于本地 v4，选择吸收 3008 截至 2026-10-19 的后续改动。保留本地独立文件工作流、完整设计、轮换独审、灵墨v7与观看收益规则；没有覆盖成服务器提示词包。

| 3008 后续变化 | 本地差距与处理 |
| --- | --- |
| 全文评估后选择情绪强度、镜头速度、额外幻想密度 | 原有方法较完整，缺稳定的前期决定及岗位继承；现并入一次集中确认，由统筹、主创、整编和独审核实际镜头 |
| 时间卡、姓名/等级说明与其它叠字分开许可 | 补载体分类、源事实保留与实际字形/位置/大小/入驻退；与幻想授权独立，禁止用“无字幕”批量抹掉源文字 |
| 实际尾首稿和来源证据加固 | 区分漏键、同义和真冲突；来源等级不随投影升级；较早状态要有持续至尾段的证据 |
| 局部返修、原声补引用和完整依赖保留 | 保全有效尾态、原声及素材依赖；逐项保留/替换/退役，不以局部反馈覆盖全稿，也不以合并旧列表复活失效状态 |
| 接入恢复、队列、暂停重连、自动导出对账 | 服务实现不搬入Skill；沿用本地已有恢复、源保真及导出工具。保留未知费用/用量，不声称有自动语义修复或无人值守能力 |

三维偏好和叠字决定详见[表现与文字合同](expression-and-screen-text.md)。快镜比例、幻想面积/时长、高潮数均无硬配额；悲痛、辨认、接触与有效静默保留。关闭额外幻想不削弱表演，丰富幻想也不突破原话、现实结果和揭示时点。

本次不修改可执行工具或测试。现有 `onscreenTexts` 是源目录，本地导出器并不自动将其全量投影上屏；许可与分类由实际读稿核验，不仿造服务器专用字段。源接入未覆盖的歧义仍保留诊断，不能把文字合同宣传成自动恢复器。

上游两项最新改动已有文档、离线验证和实际加载记录；18份当前文件hash与对应历史记录一致。但尚无按这两项新规则生成的自然作品与视频验收，旧150集完成也不能补足这一点。本地本次的结构检查与合成短场景试读范围见[验证记录](validation-report.md)；没有证明任意全剧可稳定达到某艺术水准、比3008更好或已经改善真实视频。

安装整个文件夹并保存同名旧版；已有项目的有效决定与采用稿继续有效，只按新决定和真实依赖修受影响范围，不自动重做旧剧。开发审计、用户剧本和试读稿留在包外，使用本包不需要原开发路径、历史聊天、3008服务或密钥。
