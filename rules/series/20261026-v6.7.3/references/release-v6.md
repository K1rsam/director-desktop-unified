# v6：默认主动增强

版本：`20261019-v6-active-amplification`。基于v5，按用户明确要求修订默认创作力度；不是3008新一轮运行或成片验证。

- **普通剧本也加多、加强。** 主动从源情境、关系和心理发展有效的表情、动作、互动与摄影。源没写强情绪词，不代表只能平读。自然风格与强度分开。
- **适配段落两层都加强。** 第一层是更充分、更高幅的表演与关系反差；第二层是在许可内更多、更大胆的幻想。普通题材也扫描局部机会，幻想增益包含感受、想象趣味和视听冲击，不要求新增剧情或缩短时长。
- **从提案落实到正文。** 统筹、主创、整编与独审核实际增强。事实和原话正确但具体可成立的加强机会被保守略过，须据源返修；不能一律列为可选美化。前期漏项可在已有自主推荐/采用委托内更新计划与选择后补足。
- **边界延续。** 明确限制、off、逐项取消和待决定的review仍优先；源事实、原话、知情、连续性与有效慢停保留。更多不等于次数配额、重复动作或拖长时间，强烈不等于全员吼叫或喜剧化。旧采用稿不自动重写。

沿用v5叠字分类确认、源文字目录和返修保全，沿用v4有效时间与连续声画规则。没有新增岗位、字段、调用阶段、运行时依赖或逐项审批。

本版验证范围及其限制见[验证记录](validation-report.md)。规则与文件检查不保证每次自然生成都落实到位；内容仍需独立读稿，实际视频效果另验。
