# 新场景开场参考图提示词模板

生成【场景名】进入新场景时的视频抽卡开场参考图，画面用于锁定该场景第一帧的人物初始站位与空间关系。优先使用已确认的【场景 APPROVED 资产/机位】作为空间参考，并使用已确认的【人物资产】与【服装版本】作为人物参考。保持参考图中的场景拓扑、门窗、核心家具、材质、色调和人物身份特征不变，本次只根据剧本把第一帧已经在场的人物种植到正确位置。

画面采用全景/大全景优先；仅在物理空间过小时退到中全景，不使用中景或近景。画面纯净，不加人物姓名、编号、箭头、站位线、文字或说明。

剧本第一帧依据：【原文/剧情阐述】。
人物A【角色名】：位于【位置】，姿态【姿态类别与稳定版本】，身体朝向【方向】，视线【对象/方向】，服装【版本】，手持【道具/无】。
人物B【角色名】：位于【位置】……
群演/配角：【分布与身份】，近中景可辨人物优先调用已确认群演合板，远景群体可按同一服装体系扩充。

人物站位必须优先服从剧本关系、主位/次位、对话对象、进出口、人物前后关系和动作起点；在不改变剧情关系的前提下，通过左右错位、前后层次、人物间距和视线方向做适度电影化优化。复杂姿态可以简化到更稳定的起始姿态，但不得改变姿态类别。人物表情整体压低强度，以眼神、眉眼和身体关系表达情绪。核心人物尽量不被遮挡；普通配角允许轻微遮挡；群演可以形成自然层次但不能挡住关键人物。

若第一帧人物已明确手持手机、文件、酒杯、钥匙、武器等剧情道具，必须带入；若该道具尚无正式资产，可根据剧本临时生成。不要为了下一步运动方向刻意扩大留白，只保证当前第一帧真实站位和空间关系准确。

整体继承项目最终电影调性与场景当前状态版本，保持 AI 视频友好：结构清楚、人物关系清楚、不过度浅景深、不用明显前景遮挡、不做难以连续复现的抽象光影。避免人物身份漂移、服装版本错误、场景家具位置变化、门窗拓扑变化、关键人物被遮挡、第一帧不在场人物提前出现。
