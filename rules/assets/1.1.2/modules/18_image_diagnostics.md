# 18 Image Diagnostics

用户只说“这张不对”时，不直接乱改。先给极短候选：人物不像 / 服装不对 / 场景结构不对 / 构图不对 / 光影不对 / 色彩不对 / 电影感不够 / 其他。

诊断顺序见 SKILL.md 第13节。

7视图人物：单一视图区块错误优先局部编辑；多个视图同时人物/服装一致性失败则重做相关范围。同人仅换装时，即使下排多处失败也只重做下排，禁止重画已锁定上排；按主文件第4节原像素合成。
场景多机位：当前机位错误只修当前机位；母场景拓扑错误先修母锚点，再重做受影响机位。

一次目视合并该图已发现的硬问题，记录错误证据／保持内容／修改目标。同一缺陷连续两次返修无改善时，先改模板、参考职责或编辑方法，不继续近义改写重抽；批量调度及最终清修见 [批量生产模块](21_batch_production.md)。
