# 01 Project Intake

## 目标
接收完整剧本或单资产需求，确定项目模式与前置条件。

## 完整剧本模式
禁止立即生图。先确认/推荐：
1. 题材、时代、叙事气质。
2. 3 套基础视觉方案。
3. 每套 2–3 个最终电影调性。
4. 每套人物前缀示例 + 场景前缀示例。
5. 询问是否有项目风格参考图/视频；有则分类为项目风格参考、人物参考、场景参考、排版模板参考。

接入剧本时先检测每集是否存在连续的 `场景：`、`人物：`、`道具：` 三行资产清单。存在时启用结构化清单模式，由该清单确定正式出图范围和文件名；正文用于补充视觉细节，不另起一套资产清单。

## 单资产模式
若项目视觉圣经已存在，直接继承；否则先询问视觉风格与参考图。

## 输出
- intake_summary.md
- 待确认项
- 下一步建议
