# 16 GPT-image-2.5 Prompt Compiler

本模块产出的 `.md/.txt` 是内部工作文件，默认不放入用户最终交付文件夹。

## `.md`
保留模块化结构、锚点、评分、扩展逻辑、最终成品提示词。

## `.txt`
`资产编号 中文名｜资产类型` + 一整段可直接复制到 GPT-image-2.5 的高信息密度自然语言提示词。

## 顺序
模板风格可保留，但以下必须前置：
1. 当前任务类型
2. 主体
3. 不可变核心
4. 关键服装/空间结构
5. 参考图职责

核心硬约束融入正文；专项避错集中在结尾短段。

## 最终交付边界
用户未明确索要提示词时，只交付一个扁平图片文件夹。文件夹内不含 `.md/.txt`，图片按资产类别以 `角色-`、`场景-` 或 `道具-` 开头。
