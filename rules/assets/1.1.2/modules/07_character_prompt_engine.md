# 07 Character Prompt Engine

## 永久锁定：1:1 单人人物 7 视图资料板
除群演合板外，所有单人人物资产板严格使用 1:1 正方形画布。

上排：正脸 / 向右纯侧脸 / 向右45° 3/4脸。
下排：正面全身 / 向右侧面全身 / 背面全身。
最右侧：放大的正面上半身服装展示。

上排：不穿衣服，仅头颈肩/少量锁骨；无饰品；白棚柔光；表情中性、气质存在；保留完整真实五官。
下排正面、向右侧面和最右侧放大上半身：穿完整服装；脸部用纯白色不透明涂抹完整遮挡五官；白色只覆盖面部区域；无手持道具。
下排背面：穿完整服装；保持自然后脑和发型，不出现白斑。

整张：1:1 正方形、纯白背景、无边框、无文字、无编号、无Logo。

## 同角色不同服装
禁止把完整人物资产板作为整板图改图底图。独立生成新服装板下排后，从该角色 APPROVED 身份母版裁切上排 3 张大头，以原始像素 1:1 复制到新图上排对应位置。禁止缩放、重采样、AI 重绘、修脸、锐化、调色、补帧或生成式蒙版；上排必须与身份母版逐像素一致。

任何模板都不得改变该版式与换装合成流程。
