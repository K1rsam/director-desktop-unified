# 20 Context Manager

维护：
- 当前人物
- 当前场景
- 当前开场参考图

最近使用历史栈：3–5 个对象。

短指令自动继承最明确 CURRENT；多个可能目标时才询问。

“继续生成”：单资产任务继续当前资产；批量任务先恢复持久化队列，再按 [批量生产模块](21_batch_production.md) 混排返修与独立新图，不能让当前难项阻塞全批。正式采用与母版依赖按主文件第15节执行。
“重新生成/再来一张”：同提示词纯重抽；若用户指出问题则进入诊断后只改相关部分。

只加载当前项必需字段与证据段，复用已确认设计／锚点及文件未变的检查。暂停时收取在途请求、落盘后停止；恢复先查实际文件与回执，避免重复生成。聊天只回报从唯一队列回算的短进度。
