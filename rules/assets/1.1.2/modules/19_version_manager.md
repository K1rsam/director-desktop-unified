# 19 Version Manager

- 小改：v1.1 / v1.2
- 核心身份、场景拓扑、关键服装结构变化：v2.0 / v3.0
- 历史版本不删除
- CURRENT 指向当前正式版本

## 目录
- APPROVED
- ALTERNATES
- REJECTED

APPROVED 必须有用户确认或明确委托后的受托确认依据；目视合格但未经采用的图仍为待选候选。受托确认不得写成用户逐张采用。连续生成和采用权按主文件第15节分别判断。

以上目录仅供内部生产与筛选，不直接交付。最终将确认图片复制到一个无子目录的扁平文件夹，并按主要用途添加文件名前缀：
- 人物、服装、年龄阶段、特约、群演：`角色-`
- 场景、状态、多机位、开场首帧：`场景-`
- 独立物件、武器、器物、载具：`道具-`

最终文件夹只含图片，不含提示词、台账、日志或质检文件；交付前检查无同名覆盖。
