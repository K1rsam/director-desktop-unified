# 全剧策划、完整资产设计与开工条件

有时长/分季目标时，本合同的“完整资产基线、核心完整设计、全范围开工”均指[已锁定季范围](season-scope-contract.md)；全剧只先做轻量阅读、主线/事实导航及季终候选。先选季终再详细拆资产，不能为满足“全剧前期”提前设计后续资产。未locked不派发生产；本季内设计与审阅标准不降低。

本合同在阶段1、2及首次分集派发前读取。目标是让后续作者获得足够的剧情理解和可用设计；可以减少重复读取、传输和机械整理，不能减少会改变人物反应、视觉身份、空间行动或声画效果的工作。已有资料能满足下列职责就直接复用，不为名称、文件数量或岗位形式重做一遍。

## 全剧导航必须可供创作使用

按[F1方法](foundation/F1.md)结合完整源文建立精简导航。保留主线目标、重要关系与利益变化、知情与揭示时点、未兑现线索和必要前接/结束边界，均能回到原文范围。源事实、人物宣称、解释和制作决定仍分开；召唤物、契约对象、投影与本人变身不能混成同一身份。

F1是阅读与供料职责，不要求复制原服务器的JSON响应、每集强填全部栏目或另造长圣经。已有事实/状态账、分集接入和带出处的关系/揭示/变化索引可承担同一职责。每集至少能定位影响本集理解的变化与必要前情；确无额外前情时直接记无，不重抄整集正文。只保存源行编号但下游未实际读取，不能称已供料。

阶段1终编结合F2/Q1核全范围：身份与别名、必要形态/服装的生效范围、世界事实和人物知情、事件因果、动作依赖与必要空间功能。先回读原文解决能解决的问题；真正互斥事实或关键制作取舍按既有用户决定处理，仍无法解决时只阻塞真实依赖。提取成功、目录数量和源哈希不等于这一步已完成。

## 表现决定进入实际供料

按[表现与文字合同](expression-and-screen-text.md)将全剧阅读后的情绪强度、镜头速度、额外幻想密度及分类叠字选择并入既有集中决定。采用与建议分开，保留用户已有授权；不设统一快镜比例、幻想时长或每集高潮数量。各岗位实际读取本次适用决定及源依据，整编和独审对照实际画面核兑现，不能只传“强烈/丰富”标签。

源有剧情系统时，先按[系统呈现合同](system-presentation.md)核原文：已明确的呈现方式直接沿用，由主控在可见执行消息说明形式与源依据，不重复要求选择；只有未明确、实质冲突或用户要求改编的范围才展示候选。保存逐系统实际采用依据及可见/可听/接触边界；反复可见的载体或化身纳入核心设计，纯声源保留声音身份。资产岗和主创不自行改源设定；同版记录须进入本次direction供料。

## 完整设计先于短生产卡

阶段2按[基础资产形象设计](foundation/asset-image-design.md)逐项形成可采用的文字设计，继承项目已确认的视觉方向。这个阶段不生成图片，也不提前写本集表演，但要解决会影响分镜的稳定外观、空间结构和物件功能。

先分清稳定母设计、分集有效状态和镜头动作：脸/服装大形、场景布局、关键道具结构归母设计；当拍持有、伤势、污损、知情和数量归有源时点状态；转头、拿放、站位和接触相位归分镜。仅新增某集持物或姿势不修母卡；确实形成需要独立辨认/复用的形态或参考图时再建采用变体。不能将未来事件状态倒灌基础形象，也不能用“瞬时”掩盖真正的视觉差异。

每项正式视觉资产保留以下材料；简单物件可写得短，完整性按适用内容判断，不按字数或统一字段数量评判：

- **源约束**：身份、物种、外观、服装/形态、尺度、持有关系、空间/道具功能及适用时点，保留出处；无信息明确标未知，不能从名字猜。
- **完整设计正文**：人物的脸、发型、体型、服装层次与必要穿戴；兽类的轮廓、肢体、皮毛鳞羽与尺度；群体的共性及必要识别差异；单一场景的布局、出入口、地标、陈设、材质、可用表演空间；道具的形制、比例、材质、关键结构与操作条件。只写本项适用内容，源没有限定的部分标为设计补足。
- **补足与开放项**：每项补足与依据、采用/候选状态、授权范围；剧情关键通路、藏身能力、空间关系和道具能力不能伪装成普通美术自由。
- **复核采用依据**：逐条回核源约束，比较同身份各状态、常用空间及共同设计，检查功能可用、区别可辨和时点正确；记录采用版本、源/方向依据及真实审核方式。
- **短生产卡**：由已采用完整设计提炼，只传本集会用到的识别和行动约束。完整设计在总库保留；裁剪短卡不能丢掉本集关键出入口、遮挡、持握结构或形态限制。

完整设计采用写入总库的 `design.full`，短卡仍为 `design.text`，形状见[统一资产合同](asset-registry-contract.md)。风格说明、漂亮形容词和“已读/已采用”标签不能代替设计正文或逐条核源。旧项目只有短卡时保留旧成果并标需要补设计，不能仅把同一段复制进full就声称恢复了完整设计。

## 前期范围与分集开工

完整资产目录在阶段1建立；阶段2按全剧用途和首次使用标明共同设计依赖。主角母版、当前要用的主要形态/场景/关键道具及其真实上游依赖先完成完整设计和跨项复核，本集这些条件就绪即可开工。远期独立核心项继续按首次使用提前完成，不作为全部分集的统一等待门。全剧目录与安排仍保留，不能只看首集后遗忘后续依赖，也不按数量配额划核心。

正式可复用视觉资产按首次使用提前完成同样的设计和复核，不能降为先给短卡、以后生图时再想结构。有据固定部件沿场景设计；一次性普通物件给支持动作的最小一致设计，不强扩成全剧美术任务，但独立props仍须按[资产合同](asset-registry-contract.md#普通制作对象的分流)完成PR登记与真实消费。纯声音身份、仅被提及项和无需独立素材的临时表演不强造图片。本次已授权范围内的未来形态可按首次使用提前设计，实际供料仍按源时点选择；季范围外仅留导航。提前设计不等于提前入画。

主代理在现有阶段记录中保存一次前期复核：实际源范围、导航/事实账、当前方向、资产基线快照、前置设计范围及采用版本、其余资产的首次使用安排、未解决问题和真实依赖。读过并核过这些内容后，才派发依赖它们的分集主创。独立上下文可用时复用空闲槽对跨集身份、形态和空间重点交叉核对；没有则如实记录总导演自审，不冒称独审。用户已有集中确认与常规设计委托继续有效，不把内部质量复核改成逐资产用户审批。

后期某个独立核心项因真实源冲突暂时未定时，标清它及派生设计的受影响范围；其它已完成共同前期复核、又不依赖该项的集场可以推进。不能把这记成“全剧前期全部放行”，也不能反过来用一个无关远期缺项拖住全部创作。共同主角或常用母场景未完成完整设计时，依赖它们的四路不能只靠短卡先开工。

分集作者、整编和非作者复核必须实际读取本集源文、必要导航、当前状态，以及本集所用正式视觉资产的完整采用设计和有效源依据，具体按[供料合同](context-and-dispatch.md)提取相关项；短卡只作索引和投影，不替代完整设计读取。资料仍缺则局部回补，不能由各路各自重造同一人物、空间或道具。通用创作技能中“缺图时使用最小一致文字基准”的回退，不得被用来跳过本工作流正式视觉资产的完整设计。

已有分集稿不因本合同更新一律作废。保留已成立的声画，按新补设计与真实依赖核对；只有不一致或确有质量损失的局部返修，继续使用当前总库、版本和消费回执。

## 可简化与必须保留

| 可以简化的执行成本 | 必须保留的结果与判断 |
| --- | --- |
| 同一材料反复粘贴；不变规则每集重读 | 完整源阅读、必要前情被实际读取、身份/知情/状态不串线 |
| 服务器/数据库字段、任务路由和额外中间表 | 全剧导航、源证据、完整设计、采用依据及版本可回查 |
| 每项另起一个AI调用；普通设计重复询问 | 按源完成设计、功能/空间可用、跨项一致及有依据的采用 |
| 机械命名、校验、格式打包手工操作 | 主创、整集整编、弱点检查、有效精修、内容独审和实际跨集核对 |

分镜质量按实际稿的源忠实、人物反应、情绪发展、空间动作、观看变化与声画节奏判断。工具PASS、规则字节一致、内部评分或前期耗时都不能证明与其它工作流质量相同或更高；只有同源、同方向的实际成稿对照才能支持这种结论。
