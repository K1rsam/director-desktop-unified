# 桌面流程版：来源归纳与取舍

本版以桌面端的生成、修订和采用链为骨架，以现有 v6.5 的创作方法与灵墨 v7 工具为底座。新包独立命名为 `desktop-storyboard-director`，不覆盖原 `series-storyboard-director`。运行只读包内材料，不依赖以下研究来源。

## v1.1实际执行链更新

本轮设计依据已核桌面基线 `7cd4ab5d9f668eebedaa54753b7cf942529b2f88`。其普通制作上下文合同于10月20日20:07新增，晚于v1.0创建，不能说旧包当时漏搬尚不存在的提交；本次把它与更早已有的声音事件、整编定位原则适配为Codex实际工具和岗位输入。发布前只读复查时原工程已推进至 `9570afb809c04b1434de05c538b0c8f6797cd91d`（执行策略设置修复，工作区干净），两提交间无第三阶段pipeline修改；本次没有修改原工程。

v1.0的22份creative文件与series v6.5同内容；这不证明路由调错，也不证明共享成熟方法没有价值。v1.1保留共同方法，直接修改统筹/主创/整编/精修入口并用stage3-task在开工前携带实际规则正文；不再依赖执行者恰好读到附加流程说明。普通集的统筹与主创同次完成，整编仍读完整稿，field-patch/delta保全未改声画。源绑定非人声事件已进入materialize/check/export/verify链，严格保持原源。

外围按真实依赖减负：稳定母设计、分集状态和动作分开，普通物件不泛化成全剧美术任务；远期独立设计不阻塞当前集。资产兼容和内容独审复用仍由主控核差异，未声称自动语义判断。两集隔离整编对照、实际镜号及结论边界见[本版验证](validation-report.md)。不由工具数量推断总体质量或速度优势。

## 桌面会话中需要保住的经验

1. **完整迁移创作方法。** 桌面端曾出现规则存在却未真正进入执行输入、画风加载不全的问题。新包把执行指令、源资料、候选稿分层，岗位只加载所需完整方法，并记录实际读取版本。
2. **三岗各有作用。** 情绪统筹先形成完整事件的情绪契约；主创在同次写身体、摄影、声音和光影；整编换新上下文读完整源和整集稿后直接改作品。不能把整编压成只报错，也不能拆成各专业机械补栏。
3. **材料为下游具体用途服务。** 前情和长期事实要保留，未来情节和父形象只作有标签的背景。完整资产设计采用后投影短卡，第三阶段不重复造资产，也不把整集资产全塞进每个单元。
4. **修复十几秒单镜的成因。** 检查是否把一句长原声硬绑一个镜头，先形成自然声画再定切点。2–5 秒只是常见参考，不新增镜数配额，也不为了短镜把原句读碎。
5. **连续动作按作用与相位判断。** 跨单元可继续同次动作，不因再次出现同一动词就判重演；检查接触、施力、结果和尾态是否重复或倒退。
6. **采用与汇总只有一个来源。** 保存完整候选，核验后采用；全剧视图从实际采用集稿汇总，不能维护第二份会漂移的总正文。中断先恢复原结果，不把未采用稿或文件最新时间当采用。
7. **普通错误在原流程内修。** 缺字段、超限、场景头污染等问题回原岗位和关联范围修；同类问题有界尝试。真正源冲突或超授权改变才停到用户裁决。

当前 Web 已是 `opportunity-coverage-v2`，支持许可内多批补漏，不能再迁入旧版“后批永远不能补”的限制。本地沿完整计划、选择、正文候选同版核后采用；差量工具本身不替用户改变幻想许可或添加候选。

v6.5 的创作方法与 Web 同源但并不逐文件相同。现有 Skill 的“观看收益与声画取舍”、数量账不等于逐件展示、兽语译意/契约传声等增益继续保留；不能因 Web 有指定提交就整体覆盖它。源明确系统按源执行且可见说明；只有未定部分才提出选择。制作子代理模型与强度沿工程已选配置，首次确实未选才集中询问。

## 没有照搬的部分

- 桌面内部 `integer-video-units/v1` 不进入 v7：29.4 秒的内部镜头和声窗仍为原值，外层容器才写 30 秒；4 秒以下容器不代表要拖演凑满。
- 桌面 Rust 全文绝对 UTF-16 坐标不直接进入物化工具；本包用规范化 `quote` 内的相对半开区间，明确 profile 并拒绝切开 Unicode 代理对。
- 不照搬账户、付费预算、数据库、CAS、媒体通道、原生 UI 确认按钮或 Web 每任务仅一次精修/CHAIN 只预览等产品限制。
- 不声称说明文本实现了桌面事务、网络恰好一次提交或自动语义判断。现有文件/hash/领取工具按自身合同运行，共享写入由主控串行。
- 桌面原生JSON/SQLite不是本地bundle，本包不提供通用数据库导入。声音事件使用v1.1源绑定决定与相对quote区间，不能只改枚举或删人声过检。
- 桌面工作区新增的 `UNIT_DURATION` 有界修订和 LOC-PROP 设计协同仅借有效原则，不称其已提交或已在本次运行验收。

## 如何评价本版是否更好

机械能力先以锁源、完整原句、未改内容、引用、时长及输出反解验证；本次结果见[验证记录](validation-report.md)。这些验证不能替代审美判断。

实际比较固定完整源、作者基稿、方向、宿主模型/强度、幻想许可、资产快照及容量。逐镜对照情绪、身体接触与空间、自然原声、观看发现和真实尾态；记录具体保留、变化和不足。两集隔离整编只能支持所见样本，不宣称“桌面版一定优于3008或v6.5”，不等于从头全剧生成、平台实导或成片验证。
