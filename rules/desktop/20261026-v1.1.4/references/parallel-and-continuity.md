# 主控调度、执行者轮换与跨集承接

分集四路开工前先满足[前期质量合同](preproduction-contract.md)；全源资料整理可按范围协作，但不能把四路首集短卡齐全当全剧策划和核心完整设计已完成。选季项目先冻结[productionScope](season-scope-contract.md)，所有逻辑队列均从投影索引创建，不先开全集队列再寄望作者自行停止。常规供料带必要导航、当前状态及设计索引；按[供料合同](context-and-dispatch.md)实际读取本集所用完整采用设计，不能仅将其留作短卡不足时的可选回查，也不能各路自行重造。

## 执行位与文件责任

按实际episodes源序建立至多四个连续逻辑队列，不假设集号从1连续。队列是续作次序，不是某个智能体的长期身份；每队列逐集交接，执行者按小批次轮换。默认队列数为 `min(4, 实际活动槽-1)`，也可保留四队列分时执行；报告必须分清队列数、实际执行人数和审核人数。

主控不负责任何创作组，仅统筹、决定、审核及合并；源接入、设计和分镜创作任务均按范围委派。四活动槽含主控，因此最多三名子执行者；宿主实际支持五槽时可四名。不能虚报容量，也不为并发创建用户侧新聊天或后台任务。无子代理能力时先报告执行条件缺口；已有只读审查可继续，不默认恢复主控创作。

派发前读[有界供料与轮换](context-and-dispatch.md)。默认每位作者最多领取2集，复杂集或反复返修时1集；上限可配置1～3集。首次宿主压缩或实测单响应输入达默认60,000 Token时，保存当前采用/候选及问题，在当前完整工作包边界交接，不再开本集下一包或下一集。阈值是可调的运行护栏，不是已证最优值。新接任者使用独立上下文（支持时 `fork_turns:"none"`），不得通过改owner名继续使用同一旧聊天。

每组当前集完成可用文字稿后才接下一集，同集统筹→主创工作包→整集整编保持源序；统筹与完整主创连续完成，整集整编固定换新上下文，按[单集内交接](workspace-contract.md#单集内交接)接管同集。不能把四路拆成同集四专业接力。主代理发任务时提供实际可读的本集source/约束/相关卡与底稿路径，子代理必须读到内容再创作。明确允许写入的分集目录；不得直接改共享事实、用户决定、其它组采用稿或最终合并文件。作者完成自查和机械检查可按[本地采用合同](production-contract.md)以reviewMode:self登记文字采用、继续组内下集；待独审不是等待前集文字稿的理由，也不能被写成independent。

子代理将完整成果、实际入口/出口及核对写入文件，回主控仅给路径、版本、覆盖、承接状态和待裁决坐标。主控针对问题读取必要原文/成稿；常规独审交新上下文审阅者，不把每条中间整稿/日志重新搬进主控。工具仅限制领取与登记证据，不会派模型、验证新上下文身份或证明质量；不以mtime代替明确采用记录。

资产共用[统一总库](asset-registry-contract.md)。子代理只在本集目录写补项申请，不分配全局ID、不改共享库；主代理读取当前版本核源/核重，用apply合并并下发采用ID、正式键、资产版本及短卡。两路提出近义名称时先核是否同物；baseRevision过期则读取新库重核，不能覆盖。作者落实实际画面和绑定后交sync回执，主代理才关闭该范围的补项。

## 可见进度与估时

主控负责把实际执行结果写入用户可见的执行进度消息；工作区日志、工具输出和子代理摘要不能代替这一说明。开工/恢复先说明本次范围、当前阶段和基线；阶段切换、采用/独审闭环、阻塞/解除及批次交接后及时更新。持续工作时，可交互执行期间不超过60秒没有可见更新；等待采用有界工具调用，长调用返回后立即补报。没有新增完成项时，说明仍在处理的具体集/工序，不编造增量或重复罗列空泛计划。

- 每次用简短一致的口径写“当前阶段｜已完成数/本次总数（本轮增量）｜在制任务｜阻塞｜下一步”。分母来自当前确认范围，未知先说明待核；局部范围不冒充全剧，派发数、最高集号和源读取数量不当作分镜完成数。
- 前期分别报完整读源/导航复核的集数、资产设计齐稿/已复核的项数；分集阶段分别报“文字采用（含整集整编）X/Y集”和“独审闭环Z/Y集”。文字采用按当前有效稿、完成记录与文件证据统计；独审按绑定当前采用稿且问题已关闭的非作者记录统计，不直接把status的complete数量当已独审。最终交付还须按本包既有条件收口。
- 有足够同阶段实测样本后，按最近实际完成批次的墙钟吞吐、当前并发和已知返修给预计剩余时间范围，并注明对应阶段。并行耗时不重复相加，分集创作估时不冒充全流程完成时间；独审、返修、承接和合包尚无样本时说明其尚不能可靠估计。样本不足就如实说明，不能只凭总集数、读源速度或默认模型给精确承诺。
- 在既有控制检查点保存最近上报的阶段、范围、计数口径、时间与估时依据，恢复后核已保存成果再续报，不重置计数或重做已完成集。沿用当前state、现行采用/兼容记录及绑定稿hash的独审证据汇总，不逐版本另写update-progress脚本，不为报进度改写采用状态或新增外部监控。

格式示例，数字仅作演示，不可套作实际进度：

> 阶段3·分集制作｜文字采用35/150集（本轮+2）｜独审闭环30/150集｜在制：第36、76、116集｜阻塞：1集待补料｜下一步：整编与独审交接。

## 最小必要输入

| 消费位置 | 常规材料 |
| --- | --- |
| 情绪统筹 | 本集完整源文、精简全剧方向、当时有效状态、相关承接底稿 |
| 主创 | 当前完整工作包、相关完整采用设计及短卡、源顺序前包实际采用尾态 |
| 整集整编 | 新上下文读取本集完整源、全体工作包、当前关键事实、情绪契约、所选幻想和相关设计 |
| 局部精修 | 关联完整成稿、情绪契约、所选幻想、问题坐标及受影响源依据 |
| 历史补证 | 回忆、旧承诺、身份揭示、视觉呼应或冲突时按坐标取原文 |

全剧事实库保留，但不用“人物又出现”拉取其全部历史。远期仍有效事实不能只靠最近一集背景代替；用发生/解除/适用范围核当前有效性，未来知情不提前泄漏。补料及设计修订定位直接消费者和真实设计依赖下的派生卡/消费者，旧采用稿确有依赖也须局部复核；历史快照和回执不原地改写，使用位置调整另存新修订。

## 边界与实际尾态

1. 仅从本生产链明确选定且与当前源/约束兼容的前集采用稿取actual；不读落选稿、最新文件或统筹预测冒充实际。
2. 前稿未到时，读取前集完整相关尾段与本集必要开场，保留坐标、源哈希和未知项，以PRELIMINARY完成可独立制作的文字稿。此状态允许组内继续，不代表实际连续链已放行。
3. 自由设计若是连续动作不可缺的共同条件，在前集主创开工前登记最小DESIGN约定；只锁必要关系，不预写镜头。前集已开工后不拿后集预测倒逼前稿。
4. actual到达后核关系：DIRECT才按实际可继承状态接续；TIME_JUMP、LOCATION_CHANGE、FLASHBACK、FANTASY、INDEPENDENT、UNKNOWN不能无条件继承姿势、持物、知情和身体状态。不同关系不等于无须看原稿。
5. 一致只留核对记录；自由设计差异修实际依赖入口；源/锁定约束冲突修违反的一方。后集自己的预测不成为源事实。不能删冲突、改状态或重写整集假装解决。
6. 正式全范围交付前，范围内必要实际边界必须核完；单集/前集不在范围时记NOT_IN_SCOPE及未核实际稿限制，不无限等外部稿。

缺键、同义表达与真实矛盾分别裁定：前稿漏写某个尾态字段不等于相反事实，读取双方实际相关正文与源证据，保留缺键记录，不能猜填“已继承”。同值、同证据等级的合法新增引用不等于状态变化；较早单元证据要证明持续至末段且无中间改变，未知或冲突不能自动延续。源事实、角色宣称、解释、设计与指导文字的等级在短卡、投影和返修中保持，不因改名升级为SOURCE。

复核报告绑定双方当前采用稿哈希与原文依据；稿变则旧核对失效。工具检查哈希和报告存在，关系与源语义由实际阅读核对，不以MATCHED字符串自证。

## 局部阻塞、修复与续接

缺料/来源冲突只停真实受影响组及依赖，其他组继续。先保存已到稿及问题；源变化核实际消费依赖，创建新版本，只返修受影响单元和必要邻镜。运行中记录不自动重派，恢复时先检查已保存成果，再显式回收确已中断的执行位，避免重复生产。

独审以单集为范围，优先给非作者的新上下文。主控可针对关键集亲自审核；常规完整内容审核由审阅子代理承担，不用作者摘要替代源文与完整稿。作者在采用后释放执行位，可先让新审阅者用该位核一集再派下一批；无需等全剧结束，也不超过宿主活动上限。审阅者仅写问题卡，返修交原作者尚有效的小批上下文或携问题/原稿的新作者，主控不代写。

作者自查及整集整编完成后，可登记self文字采用并在批次额度内续作；达到轮换条件必须换新执行者。每批收口即处理其独审与局部问题，不积压到全剧结束。审阅者回查修后版本；未改正文只新增独审记录，改正文则显式恢复受影响集并重核真实下游。最终主控检查独审与采用版本一致，不能仅凭complete、readyForDelivery或自评放行。无独审条件可如实报告已审范围，但不因此放宽主控不创作的职责。
