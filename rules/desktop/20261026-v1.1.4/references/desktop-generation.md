# 桌面生成链在 Codex 中的执行

本页供主控理解流程；实际岗位规则在[第三阶段入口](../stages/episode-production/SKILL.md)，由stage3-task在开工前携正文派发。运行不依赖桌面程序、旧会话或其它Skill，也不模拟桌面UI采用按钮、数据库事务和付费执行器。

## 1. 主线与权威

**必要全剧准备 → 本集可用材料 → 同次情绪统筹与完整主创 → 新上下文整集整编 → 有需要才精修 → 内容复核 → 灵墨v7导出。**

| 材料 | 权威与用途 |
| --- | --- |
| 冻结源与索引 | 原文、说者、声道、因果、身份与时点；不能为过检改字 |
| 制作方向与决定 | 用户已明确的画风、表演、幻想/叠字/系统形式、容量；推荐不等于授权 |
| 已采用资产设计 | 当前形象、适用范围、空间结构与操作条件；设计不冒充源事实 |
| 计划与候选 | 创作过程可回查；文件存在或机械通过不等于采用 |
| 当前采用稿与实际尾态 | 后续真实承接和导出依据；预测、mtime与落选稿不能代替 |

保留不可变源/候选/采用版本，在既有检查点记录当前角色、范围、源/方向/规则/资产/基稿与结果。不另建重复故事摘要或任务数据库。

## 2. 前期只保留有消费者的工作

有分季目标时先轻量全读并按[季范围](season-scope-contract.md)锁定完整原集尾，再只为本季展开详细接入和设计；没有分季目标时保持完整输入范围。完整读源，建立轻量导航、事实/知情/状态索引与资产目录，满足后续身份、时点和因果查询。共同母设计及当前集实际依赖先完成，远期独立设计按首次使用推进，不全局停工。已有有效完整设计直接复用；当前所用视觉资产完整采用设计实际进入主创、整编和独审供料，短卡只作索引，不以“短卡够用”省略正文。无关设计、重复 standardPackage/intakeEvidence 和历史审核流水留原文件回查，主控一次去重供料。

稳定母设计、分集状态和镜头动作分层：场景火灾不倒灌原母场，某集拿杯不修改人物母卡。普通对象按[资产分流](asset-registry-contract.md#普通制作对象的分流)处理；场景固定部件沿SC，一次性物件最小设计，独立props仍守PR登记。真实复用/关键图面才完整独立设计。源冲突只阻塞真实依赖。

## 3. 开工材料直接到达岗位

[stage3-task](context-and-dispatch.md#文件包工具)从现有文件/hash/JSON Pointer投影，明确production/context/entry/nextBoundary/support；制作源完整，前情不重演，实际前尾不伪造，后边界不抢拍。资产按当前生产、历史证据、父设计材料分别说明用途，不把同一个人在任何年代的卡都当当前入画图。

包内装入common、真实岗位段和当前需要的完整创作方法正文，执行者实际读取；不能仅发路径、使用错误岗位标签，或在已有候选后补包冒称供料。author无plan时同包完成统筹与选择再写稿，有plan沿用；普通集不新增planner调用。完整内容超限先去重复和无关项，确需时有据调限，绝不截源或摘要审稿。

## 4. 创作方法与工具各做其事

统筹交刺激、应对、真实结果和独立情绪落点；主创同次共同设计身体、摄影、声音和光影，获准幻想进入同一声画进程。创作前独立冻结源并绑定岗位与采用稿；原声物化保逐字及源序，长句可不断声跨镜；真实非人声按有据声音事件演绎，不朗读描述。方法细节直接进岗位规则，本页不再复写教程。

整编必须读完整源与全稿，工具提供源锚时间线和实际镜文 `cut_pairs`，仅定位、无分数；核同一动作的出点与下一镜入点，少量修改仍沿字段patch。少量字段用field-patch，拆合镜头用完整关联组delta；程序复制未改正文。有效强处不因整理而削弱，零改善可结束。字段/容量错误在真实关联范围修，正常问题不重跑全剧前期，也不把2–5秒、统一字速或总秒数当质量指标。

## 5. 采用、复核与变化传播

新生成正文不直接注入源cue；源演法按说者和句内位置落实，后期人名条/指定叠字另存说明，不能吞掉源原话、系统面板或场内文字。

稳定候选按[生产合同](production-contract.md)一次完成sync/check/export/verify及完整内容核验，保存正文、预览、目录和真实资产快照。整编参与改稿，不能兼任此版非作者独审。只改格式或元数据时，核实际内容/依赖差异后引用有效旧独审；旧审查原件与新版本兼容依据分别保存，不篡改旧hash冒称重新独审。

版本号变化先看实际影响：无关资产新增不重写本集，真实设计/适用状态改变才核消费者；实际出口未变，不让后集链式重审。需要重新绑定时使用现有workspace reconcile并留新旧证据，不跳过当前版本门。进度从workspace紧凑状态和绑定稿件的独审记录派生，不维护第二份手写全集正文。

## 6. 恢复与交付边界

先查执行者、检查点、输入和已保存结果，核后续原任务；未知提交不盲重发。完整候选先复核，不因窗口更换重创作。交接只给当前版本、已核范围、有效入口/出口、未决坐标、下一动作及证据路径，完整稿留文件。

新规则用于后续任务，旧采用稿不批量作废。最终按本次范围及实际采用稿源序合并，交灵墨v7 MD、匹配白图和完整资产资料；季模式preview/final和planned/closed分别保存，续季校验实际采用尾稿并另行启动，普通全剧继续原范围。工具验证、文字内容复核、平台实导与真实音视频效果分别记录；本包不保证跨进程事务、网络exactly-once、费用或成片效果。
