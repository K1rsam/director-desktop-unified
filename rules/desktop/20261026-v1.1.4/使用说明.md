# 桌面流程分镜导演使用说明

本包为 `desktop-storyboard-director`，版本见 [VERSION](VERSION)。当前为 v1.1.4，同步全剧版 v6.7.3 的完整视觉基准和可读图片引用改进，见[更新说明](references/release-v1.1.4.md)。它与 `series-storyboard-director` 并存，不改变旧工程的采用稿和用户选择。

将整个 `desktop-storyboard-director` 文件夹放入项目 `.agents/skills/`，在项目 `AGENTS.md` 登记 [SKILL.md](SKILL.md) 即可。跨机器保留完整 scripts、references、stages、tests、agents，不能只复制入口。运行不依赖 CL、桌面 EXE、历史聊天、在线仓库、密钥或 npm 安装。

调用：

> 使用 $desktop-storyboard-director 处理这份完整剧本，按桌面生成逻辑完成资产供料、情绪统筹、完整主创、整集整编与内容复核，交付灵墨 v7 MD、配套白图和完整资产资料。

也可明确“只精修第几集”“只转换已有采用稿”“只比较技能”。未明确请求不启动图片或视频生成。已有有效方向、幻想和模型选择直接继承；首次制作缺少必要选择时集中询问。

依赖 Node.js 24+、Python 3.9+ 标准库。先运行实际 `node --version` 与 Python 的 `--version`；Windows 的 `python` 可能只是应用商店别名，可使用已安装 Python 的绝对路径。不要据命令存在就声称运行时可用。命令中的 `python3` 是示意，替换为本机实际解释器。

Node 调用 Python 时优先使用 `STORYBOARD_PYTHON` 指定的解释器，否则依次检查 `python3`、`python`、`py -3`，统一启用UTF-8。在Windows PowerShell本次会话可设置 `$env:STORYBOARD_PYTHON = '实际Python绝对路径'`；macOS/Linux可设置同名环境变量。包内不保存开发电脑路径，也不自动安装解释器。

直接运行 Python 工具时使用 `python3 -X utf8 scripts/工具名.py ...`，避免 Windows 管道默认编码损坏中文或特殊字符。包内 Python 运行和测试不需要第三方库；官方 Skill 结构校验器另需 PyYAML，它不是本技能的生产依赖。

v1.1系列在派单前用stage3-task装入真实岗位规则与材料；主创可同次统筹写稿，整编完整阅读后默认只交字段patch或完整关联组delta。源明确非人声的VO事件已有无损通道，普通物件和远期设计按真实依赖分流。常用命令见[本地工具](references/tools.md)，形状见[本地适配](references/desktop-adapter.md)。程序只能验证自己覆盖的合同；源语义、演出、观看收益与正文配图仍需读稿。

新任务按[视觉基准](references/visual-baseline.md)供给已采用的完整文字，原样进入settings和每段通用提示词；采用前用 `stage3-task.py verify-output` 核对任务与成稿，再走check/export/verify。共同风格不覆盖本段演出、局部幻想或项目声音/字幕决定。

更新在后续新派任务生效；进行中的任务保留其冻结规则与材料，旧采用稿不批量作废，不自动重跑。恢复时先核实际检查点，明确新任务采用本版；已存在完整候选先核后续作。旧任务若因入口更新出现规则hash漂移，应回查其冻结正文或安装前完整Skill备份，不能改旧回执/hash冒称原规则未变；下一任务再用本版重新构包。

新制作在创作前冻结独立源锁，保留完整相关设计供料、实际切点联修及后期文字隔离。只有用户提出分季/总时长目标时才加载[本季范围](references/season-scope-contract.md)和[季终接续](references/season-continuation.md)；不将120–150分钟套到普通全剧。新稿使用 `voice-delivery-v1`，原声演法仍须实际读源落实；旧无锁稿不因更新自动重做。
